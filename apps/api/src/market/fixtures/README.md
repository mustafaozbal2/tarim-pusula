# Kayıtlı örnek yanıtlar

Toplayıcı testleri bu dosyalarla çalışır (ağa çıkılmaz).

- `ibb_hal.json`: İBB Hal Fiyatları web servisinin (halfiyatlaripublicdata.ibb.gov.tr, Swagger) günlük fiyat
  yanıtının alan adlarına göre hazırlanmış ÖRNEKTİR; rakamlar uydurmadır, canlı kayıt DEĞİLDİR. Canlı yanıt
  bu ortamda alınamadı (Swagger şeması okunamadı). Gerçek yanıt alınınca bu dosya onunla değiştirilmeli.
- `tepge_aylik.csv`: TEPGE aylık raporundaki tablonun noktalı virgüllü biçime çıkarılmış ÖRNEĞİ (rakamlar uydurma).
- `borsa_bulteni.html`: Ticaret borsası günlük bülteninin tablo biçimi ÖRNEĞİ (rakamlar uydurma).
