# Kabul Tablosu (G0–G14)

Hazırlandığı görev: G15 (2026-10-24). Her görev dosyasındaki (`docs/tasks/Gx.md`) kabul ölçütü tek tek yeniden kontrol edildi.
Kanıt sütunu test adıdır (`dosya › test adı`); testler `pnpm run verify` (birim + API, PGlite) ve `pnpm run test:integration` (gerçek PostgreSQL+PostGIS+pgvector, Redis, Mosquitto) ile koşar, e2e `pnpm --filter @tarim/e2e test` ile.

Durum: **KANITLI** (ölçütü doğrudan sınayan test var) · **KISMEN** (test var ama ölçütün bir yanı sınanmamış; eksik açıkça yazılı) · **YAPILMADI** (kanıt yok).

Her görevde ortak üç ölçüt vardır: (a) `pnpm run verify` hatasız, (b) yeni davranışların testi, (c) kararların `docs/KARARLAR.md`'ye yazılması. (a) G15 sonunda kökten koşuldu (bkz. `.overnight/NOTES.md` G15 satırı); (b) her görevin test dosyası aşağıda adıyla geçer; (c) `docs/KARARLAR.md` G0–G14'ün her biri için ayrı bölüm içerir (başlıklar: G0…G14). Bu üçü aşağıda tekrar satırlanmadı.
