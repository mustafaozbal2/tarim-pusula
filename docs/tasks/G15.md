# G15 — Gerçek altyapıda doğrulama ve açıkların kapatılması

Önceki görevlerin devir notlarındaki (.overnight/NOTES.md) "yarım / doğrulanamayan" maddelerini kapat.

## Yapılacaklar

- Docker ile gerçek PostgreSQL+PostGIS+pgvector, Redis, Mosquitto ayağa kaldır; `PgDb`, tüm migration'lar (PGlite yerine gerçek sunucuda), BullMQ ve MQTT için entegrasyon testleri yaz (`pnpm run test:integration`, `verify`'a dahil değilse ayrı betik + CI işi).
- PostGIS koşullu SQL'lerini gerçek PostGIS'te çalıştır; eşleşmeyi (ST_DWithin) TS sonucuyla karşılaştır.
- TOTP sırrını şifrele (anahtar .env'den). MFA sıfırlama akışı. Paket/evre reddetme ve onay geri çekme. Duyuru düzenleme/silme.
- Mobil: takvim ekranı, duyuru kartı (kaynak, tarih, "Neden?"), giriş ekranı; docs/prototype ile görsel karşılaştırma (Playwright ekran görüntüsü).
- Süresi geçen OTP/oturum temizliği için zamanlanmış iş. Web için servis çalışanı (çevrimdışı).
- Jetonları cihazda güvenli depoda sakla (expo-secure-store).
- Önceki tüm görevlerin kabul ölçütlerini tek tek yeniden kontrol et, eksikleri tamamla; sonucu docs/KABUL_TABLOSU.md'ye yaz (görev, ölçüt, kanıt: test adı).

## Kabul ölçütleri

- Entegrasyon testleri gerçek Docker servislerine karşı yeşil
- docs/KABUL_TABLOSU.md her G0–G14 ölçütü için kanıt içerir; kanıtı olmayan ölçüt açıkça "YAPILMADI" yazar
- `pnpm run verify` hatasız geçer
