# G18 — Android APK ve telefonda deneme (G16 tasarımı ile)

## Yapılacaklar
- apps/mobile: EAS Build yapılandırması: `eas.json` `preview` profili (Android, buildType apk, dahili dağıtım) ve `development` profili (MapLibre native için). Paket adı com.tarimpusula.app, uygulama adı "Tarım Pusula", simge/açılış ekranı yeni palete uygun (yer tutucu logo üret).
- Sunucu adresi `EXPO_PUBLIC_API_URL`; yokken uygulama çökmez, "Sunucuya bağlanılamadı" kartı gösterir. `.env.example` örnekleri (yerel ağ IP'si).
- Telefonla denemeyi mümkün kılmak için DEMO sunucusunu yerel ağda dinleyen mod: `pnpm run demo -- --lan` (0.0.0.0, CORS, bilgisayarın yerel IP'sini ekrana yaz, Windows güvenlik duvarı yönergesi). APK bu adrese bağlanır.
- docs/APK_REHBERI.md: Türkçe, adım adım ve ekran ekran (Mustafa'nın yapacakları açıkça): (1) ücretsiz Expo hesabı, (2) `npm i -g eas-cli`, `eas login`, (3) `eas build -p android --profile preview`, (4) APK'yı telefona indir/kur ("bilinmeyen kaynak" izni), (5) bilgisayarla aynı Wi-Fi'da sunucuya bağlama, (6) sık hatalar. Claude Expo hesabına giriş yapamaz; bu adımlar kullanıcıya bırakılır ve rehberde net yazılır.
- PWA çıktısı ve "Ana ekrana ekle" yönergesi. Uygulama içi "Hakkında" (sürüm).
- iOS: şimdilik yalnız PWA; Apple geliştirici hesabı gerektiğini rehbere yaz.
