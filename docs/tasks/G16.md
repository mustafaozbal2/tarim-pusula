# G16 — Android APK ve telefonda deneme

## Yapılacaklar
- apps/mobile için EAS Build yapılandırması: `eas.json` içinde `preview` profili (Android, buildType "apk", dahili dağıtım) ve `development` profili (geliştirme derlemesi: MapLibre native için). Paket adı `com.tarimpusula.app`, uygulama adı "Tarım Pusula", simge ve açılış ekranı (docs/prototype renkleri, pusula logosu; yer tutucu simge üret).
- Sunucu adresi `EXPO_PUBLIC_API_URL` ortam değişkeninden okunur; ayar yoksa uygulama açıkça "Sunucuya bağlanılamadı" kartı gösterir (çökmez). `.env.example` içine örnek: yerel ağ IP'si (http://192.168.x.x:3000) ve canlı adres yer tutucusu.
- API yerel ağdan erişilebilsin (0.0.0.0 dinleme, geliştirme için CORS) ve Windows güvenlik duvarı notu.
- Yerelde Android Studio gerektirmeyen yol: bulutta EAS derlemesi. `docs/APK_REHBERI.md`: Türkçe, adım adım, ekran ekran: (1) ücretsiz Expo hesabı, (2) `npm i -g eas-cli`, `eas login`, (3) `eas build -p android --profile preview`, (4) APK'yı telefona indirip kurma ("bilinmeyen kaynak" izni), (5) bilgisayardaki sunucuya bağlama (aynı Wi-Fi, IP bulma), (6) sık hatalar.
- PWA çıktısı: `expo export --platform web` sonucu ve telefondan "Ana ekrana ekle" yönergesi.
- Uygulama içi sürüm numarası ve "Hakkında" ekranı.

## Kabul ölçütleri
- `eas.json`, `app.config` geçerli (eas-cli `eas config` veya şema testiyle doğrulanır; çalıştırılamıyorsa nedeni NOTES'a yaz)
- API adresi yokken uygulama çökmez, bağlantı kartı çıkar (test)
- docs/APK_REHBERI.md eksiksiz
- `pnpm run verify` hatasız geçer
