# G0 — Altyapı: monorepo, CI, tasarım sistemi, CLAUDE.md

## Yapılacaklar

- pnpm workspace + Turborepo: apps/mobile (Expo+TS+Expo Router), apps/panel (Next.js), apps/api (NestJS), apps/workers, packages/agro-core, packages/schemas (Zod), packages/ui, packages/device-sim
- Kök script `pnpm run verify` = lint + typecheck + test (tüm paketler). Bu komut her görevin kabul ölçütüdür.
- docker-compose.yml: PostgreSQL+PostGIS+pgvector, Redis, MQTT broker (Mosquitto). `pnpm run dev:infra` ile kalkar.
- GitHub Actions: verify çalıştıran CI. ESLint, Prettier, Vitest, TS strict.
- packages/ui: renkler/yazı tipi (Manrope) token olarak (docs/UX_KURALLARI.md), Button, Card, Chip, Badge, BigChoice bileşenleri; min dokunma alanı 56 px, min yazı 16.
- apps/mobile: 4 sekmeli iskelet (Bugün, Tarlalarım, Soru sor, Pazar), docs/prototype/ içindeki ekranlara birebir uygun boş ekranlar (Türkçe, i18n altyapısı).

## Kabul ölçütleri (hepsi sağlanmadan görev bitmez)
